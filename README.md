# tiny-stack-vm

[![make.fun](https://img.shields.io/badge/make.fun-bounty-7c3aed)](https://make.fun/c/tiny-stack-vm-01-run-20261122)
[![competition](https://img.shields.io/badge/competition-tiny--stack--vm--01-blue)](https://make.fun/c/tiny-stack-vm-01-run-20261122)
[![prize](https://img.shields.io/badge/prize-%24100-gold)](https://make.fun/c/tiny-stack-vm-01-run-20261122)

A tiny, fast interpreter for make.fun's tiny stack ISA v1, for the
competition "Build a tiny stack virtual machine, 22 November 2026".

One run answers a whole set: `node main.ts` reads
`/input/<id>/program.bin` and `/input/<id>/input.bin` and writes
`/output/<id>/stdout.bin` and `/output/<id>/exit.txt` for each id.
